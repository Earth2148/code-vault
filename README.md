# 🗄️ CodeVault

**CodeVault** คือแอปพลิเคชันเว็บแบบ Single-Page (SPA) สำหรับจัดการและเก็บบันทึก "คลังรหัสส่วนตัว" ของคุณอย่างเป็นระเบียบ ทำงานบนเบราว์เซอร์ 100% โดยไม่มีการส่งข้อมูลไปยังเซิร์ฟเวอร์ภายนอก เน้นความเป็นส่วนตัวและความปลอดภัยเป็นหลัก

## ✨ ฟีเจอร์เด่น (Features)

*   🔒 **ระบบความปลอดภัย:** ล็อกแอปพลิเคชันด้วยรหัส PIN 4 หลัก (ค่าเริ่มต้นคือ `1234` สามารถเปลี่ยนได้ในการตั้งค่า)
*   🙈 **โหมดความเป็นส่วนตัว (Privacy/Stealth Mode):** ระบบเบลอรูปภาพปกอัตโนมัติ เพื่อป้องกันการมองเห็นจากบุคคลรอบข้าง สามารถกดสลับเบลอได้ทีละภาพ
*   📚 **ระบบจัดการข้อมูลครบวงจร:** 
    *   บันทึกรหัส (Code), ชื่อเรื่อง, ชื่อนักแสดง, สตูดิโอ
    *   เพิ่มภาพปก (Image URL)
    *   ติดแท็ก (Tags) หมวดหมู่
    *   กำหนดสถานะ (PLAN = รอตั้งรับ / WATCHED = ดูแล้ว) 
    *   ให้คะแนน (Rating) และกดชื่นชอบ (Favorite)
*   🔍 **ค้นหาและตัวกรอง:** ค้นหาด้วยคีย์เวิร์ด, กรองตามสถานะ, เรียงลำดับตามวันที่/รหัส/คะแนน
*   🏷️ **ระบบหมวดหมู่แบบอัตโนมัติ:** แยกหมวดหมู่ตาม นักแสดง (Actresses), สตูดิโอ (Studios) และ แท็ก (Tags) ให้โดยอัตโนมัติจากข้อมูลที่คุณมี
*   💾 **Local Storage & Backup:** ข้อมูลทั้งหมดถูกบันทึกไว้ในเบราว์เซอร์ของคุณ สามารถ **ส่งออก (Export)** ข้อมูลเป็นไฟล์ `.json` และ **นำเข้า (Import)** เพื่อย้ายเครื่องหรือสำรองข้อมูลได้
*   📱 **รองรับ PWA (Progressive Web App):** สามารถกด "ติดตั้งแอป" ลงบนหน้าจอโฮมของสมาร์ทโฟน หรือ Desktop เพื่อใช้งานแบบออฟไลน์เสมือนแอปพลิเคชันจริง

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

*   **HTML5 / CSS3 / JavaScript** (ไม่ใช้ระบบ Backend)
*   **[Vue.js (v3)](https://vuejs.org/)** - ผ่าน CDN สำหรับจัดการ State และ UI แบบ Reactive
*   **[Tailwind CSS](https://tailwindcss.com/)** - ผ่าน CDN สำหรับการออกแบบ UI ที่เป็นแบบ Skeuomorphic + Dark mode
*   **[FontAwesome](https://fontawesome.com/)** - สำหรับไอคอนต่างๆ

## 🚀 วิธีการติดตั้งและใช้งาน

เนื่องจากโปรเจกต์นี้ถูกออกแบบมาให้อยู่ในรูปแบบไฟล์เดียว (Single File) การใช้งานจึงง่ายมาก:

1. ดาวน์โหลดหรือคัดลอกโค้ดทั้งหมดไปบันทึกเป็นไฟล์ชื่อ `index.html`
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ผ่านเว็บเบราว์เซอร์ใดก็ได้ (แนะนำ Chrome, Safari หรือ Edge)
3. ใส่รหัส PIN เริ่มต้นคือ **`1234`** เพื่อปลดล็อก
4. เริ่มต้นเพิ่มรหัสลงในคลังของคุณได้เลยผ่านเมนูรูป **+** ด้านล่าง

## ⚙️ การตั้งค่าระบบ (Settings)

คุณสามารถเข้าไปที่เมนู **ตั้งค่า (Settings)** ด้านล่างขวาเพื่อจัดการแอป:
*   **ติดตั้งแอป (PWA):** เพิ่มแอปพลิเคชันลงในหน้าจอหลัก (Home Screen) ของมือถือ
*   **เปลี่ยนรหัส PIN:** เปลี่ยนรหัสผ่าน 4 หลัก เพื่อความปลอดภัย (หากลืมรหัส PIN จะไม่สามารถเข้าแอปได้ ต้องเคลียร์แคชเบราว์เซอร์เท่านั้น ซึ่งจะทำให้ข้อมูลหาย)
*   **จัดการข้อมูล (Backup/Restore):** 
    *   `ส่งออก`: ดาวน์โหลดข้อมูลทั้งหมดเป็นไฟล์นามสกุล `.json`
    *   `นำเข้า`: อัปโหลดไฟล์ `.json` เพื่อกู้คืนข้อมูล
*   **Danger Zone:** ล้างข้อมูลทั้งหมดในระบบ (ไม่สามารถกู้คืนได้)

## ⚠️ ข้อควรระวัง (Disclaimer)

*   แอปพลิเคชันนี้บันทึกข้อมูลลงใน **Local Storage** ของเบราว์เซอร์ หากคุณล้างแคช (Clear Data) ของเบราว์เซอร์ ข้อมูลภายในแอปจะหายไปทั้งหมด
*   **กรุณาสำรองข้อมูล (Export)** ของคุณไว้เป็นไฟล์ `.json` อย่างสม่ำเสมอ หากต้องการเปลี่ยนเครื่องหรือป้องกันข้อมูลสูญหาย
